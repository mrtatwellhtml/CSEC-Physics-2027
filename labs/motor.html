In simple words

A wire carrying a current inside a magnetic field feels a force. This is the motor effect. Use Fleming's left-hand rule to find which way: First finger = Field (N → S), seCond finger = Current (+ → −), thuMb = Motion (force).

In a motor, the forces on the two sides of a coil point opposite ways, so the coil turns. The split-ring commutator reverses the current every half turn so it keeps turning the same way.
